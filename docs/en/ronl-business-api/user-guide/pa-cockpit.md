# PA-Cockpit

*kompas · issues*

PA-Cockpit gives provincial executives an administrative overview of dossiers and issues. It works like a compass, weighing priority and momentum, so the executive can steer in time rather than react late.

On opening the board you see dossiers and issues laid out for steering, so priority and momentum are visible at a glance.
