The partial has two modes, and a page reaches it by declaring either key: component: RONL Business API → names one component; shows its version scope: cross-cutting → describes every component at once The second mode exists because pages under docs/en/contributing/ describe the tooling across ALL components simultaneously. Stamping such a page with any single component's version would be false, and picking one of the five arbitrary — but leaving the header off entirely made "no badge" ambiguous between "no version applies here" and "this page has not been synced yet". So the header is present either way, and its right-hand fact says which kind of page you are on. Cross-cutting pages assert the docs_built date instead of a version, since that is the one date that genuinely applies to them: it is when the site was last reconciled against every component at once.
